Architecture

Five engines. One pipeline.

Every schema URL passes through a deterministic ingestion → hydration → proxy pipeline, then into the AI QA automation layer.

AST Schema Parser

Recursively resolves all $ref pointers in deeply nested OpenAPI JSON/YAML with memoized traversal. Zero exponential blowup.

resolve_refs(node, root) → Schema

Contextual Data Engine

Detects field semantics from names and types. Auto-generates realistic emails, phones, dates, addresses in English & Arabic.

{"email": "user@example.com"}

Zero CORS Proxy

Every request fires server-side via a persistent TCP Keep-Alive session. Your browser never touches the target origin.

proxy → target | 200 OK (42ms)

AI Auth Orchestrator

Kimi K2.6 reads your securitySchemes, identifies the login endpoint, and auto-acquires + injects the Bearer token before running protected endpoint tests.

analyze_auth(schema) → token

AI Report Compiler

After execution, the AI compiles a professional executive report with risk analysis, recommendations, and full per-endpoint breakdown — streamed live, exportable as Markdown.

generate_report(results) → .md
